# AI Engineering Notebooks

Hands-on notebooks covering data cleaning, classical ML, deep learning, and LLM/RAG workflows.

| Notebook | Topic |
|---|---|
| `01_customer_data_cleaning` | pandas cleaning and joins on customer/transaction data |
| `03_apartment_price_regression` | scikit-learn regression pipeline |
| `05_credit_default_business_impact` | threshold tuning by business cost |
| `06_premium_subscription_ensembles` | Random Forest vs. XGBoost, overfitting diagnosis |
| `08_stress_detection_pytorch_mlp` | PyTorch MLP for binary classification |
| `10_llm_api_log_analysis` | token efficiency, temperature vs. hallucination |
| `11_llm_structured_extraction` | LLM JSON extraction with Gemini |
| `13_chromadb_semantic_search` | embeddings + ChromaDB with metadata filters |
| `15_rag_evaluation` | context filtering, citation validation, Hit@2 |

Datasets are not included. Notebooks were run on Google Colab.
